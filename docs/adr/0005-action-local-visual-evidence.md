# 0005. 在动作读回中提供局部视觉变化证据

- 状态为已采纳，P7 缺陷修复，版本 0.5.8。
- 背景为 QQ 音乐播放图标变化在半采样全图中只有 27 个像素，占比约 0.011%，全图阈值 0.5% 会漏判，横幅轮播同时会产生大量背景变化。
- 决定为保留全图比较，复用相同图像并在原图分辨率比较控件外扩区域及动作点周边，分别返回局部和全局证据。公开返回增加区域、阈值、步骤、内部帧身份及 SHA256，沿用有界且按会话隔离的图片缓存。
- 后果为主模型能识别小范围视觉反馈并区分全局动画来源，局部悬停和焦点变化也可能命中。业务完成继续使用期望条件与读回验证，区域大小和阈值后续通过真实样本校准。
