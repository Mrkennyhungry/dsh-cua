## Historical cursor sheets

Both sheets were generated with the built-in imagegen tool with transparent
background enabled. The user reference was the input to the action sheet; the
action sheet was the input to the thinking sheet. Runtime PNG frames are sliced
and downsampled with nearest-neighbor by `scripts/build-cursor-sprites.py`.

Preserve very closely her recognizable design: huge rounded head, wide dark blue shiny eyes with large pale blue highlights, tiny calm pout, pale peach round face, subtle pink cheeks, thick blue gradient bob/long side hair, white frilled maid headband, dark navy maid dress, pale blue ribbon and small blue whale fin ears. Remove all surrounding UI, text, borders, background; reconstruct complete petite chibi full body with tiny feet and small whale tail. Match reference face charm, no generic cat ears, no blocky robot face. Create a clean sprite sheet on transparent background with exactly 3 rows and 4 columns of equally sized square cells, consistently centered and same scale, NO TEXT. Each sprite designed on a 48x48 logical pixel grid, crisp pixel clusters and limited palette, nearest neighbor enlarged, no blur or antialiasing, polished game sprite quality. Row1: idle pose, idle blink, swimming/moving pose left, moving pose right. Row2: hand raised to pat/click target at upper left, pat hand down with tiny impact sparkle at upper left, typing with small keyboard hands up, typing keyboard hands down. Row3: scrolling with tiny arrow, pulling/dragging tiny handle, observing with magnifying glass, surprised error expression. Character consistency across all frames essential, reference face faithfully retained. Large clear gutters between cells, each sprite fully contained. Full sprite sheet 768x576 or matching 4:3 ratio. Transparent background.
